# plp-python-week3 Grade Reporter & Bug Hunt

## Files
- grade_reporter.py - Loops through a list of scores, assigns grades using if/elif/else, counts passes/fails and calculates average.
- bug_hunt.py - Fixed version of a broken while loop that sums 1 to 5, with 3 BUG comments explaining fixes.

## Reflection
The hardest bug to find was the logic bug where count < 5 only summed to 10. I knew something was wrong because there was no error message, but the program printed Sum of 1 to 5 is: 10 instead of the expected 15.
